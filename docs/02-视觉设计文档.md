# 搬伴 · 视觉设计文档（Demo）

> 范围：Web 前端的视觉层。功能以 `docs/01-功能设计文档.md` 为准。  
> 方向：气质像小红书，结构仍是 Web 计划台。不做发现页瀑布流，不做 App 底栏，不把整个产品做成笔记详情页。

---

## 1. 目标与边界

路演在浏览器里打开。评委应感到「这是熟悉的小红书红 + 白底内容」，主场仍是双轨搬家计划。

| 要像小红书的 | 不要做成小红书的 |
|---|---|
| 品牌红、白底灰画布、软黑字 | 双列瀑布流首页 |
| 胶囊主按钮、12–16px 卡片圆角 | 底部 Tab（发现/购物/我） |
| 近乎无阴影、红只用在强调 | 手机外框套一整站 |
| 系统中文黑体 | 全站只有图、计划信息藏进封面 |

**唯一例外：** 转卖帖和房源详情是一张笔记卡（上图下文 + 标签）。它们是产物，不是产品导航。

标志用 `assets/logo.svg`，不用小红书 LOGO。文案写「小红书帖 / 转卖帖 / 来源 小红书」即可。

---

## 2. 规范从哪来

小红书没有公开的 C 端 Design System。本 Demo 用的是：

1. 品牌色 `#FF2442`，按钮层 `#FF2E4D`。
2. 官方小程序设计规范里的交互原则：一页一个主操作、文案短、少弹窗、间距走 4 的倍数。见 [设计规范](https://miniapp.xiaohongshu.com/doc/DC519927)。
3. 生产站点可核验的中性色：白 `#FFFFFF`、画布 `#F5F5F5`、`rgba(48,48,52,.05/.10)`、软黑字、卡片默认无厚阴影。

---

## 3. 设计原则

1. **红是动作。** 生成计划、用示例房间、选一套、置办家具、就这套、复制文案用红。大面积不铺红。
2. **空的地方就留白。** 旧房没有照片、新房没有选中、还没点置办时，用虚线空态和一句说明，不先堆满卡片。
3. **图让给旧物、房间和房源。** 预算和日期用字。划线标在「你的要求」原文上。
4. **平面分层。** 白卡片坐在 `#F5F5F5` 上。子流程用右侧栏，不用厚阴影对话框。
5. **Web 桌面优先。** 内容最宽 1120。窄屏双轨上下叠，不做假手机 App。

## 4. Token

落地在 `css/app.css` 的 `:root`。

### 4.1 色

| Token | 值 | 用法 |
|---|---|---|
| `--red` | `#FF2442` | 强调、划线、文字按钮 |
| `--red-btn` | `#FF2E4D` | 主按钮 |
| `--red-press` | `#E01F3D` | 主按钮按下 |
| `--red-tint` | `#FFECEF` | 划线底、选中 |
| `--star` | `#FDBC5F` | 已选房源上的星 |
| `--canvas` | `#F5F5F5` | 页面底 |
| `--surface` | `#FFFFFF` | 卡片、顶栏、侧栏 |
| `--fill-1` | `rgba(48,48,52,0.05)` | 浅底 |
| `--fill-2` | `rgba(48,48,52,0.10)` | 次按钮、输入底 |
| `--title` | `rgba(0,0,0,0.80)` | 标题 |
| `--body` | `rgba(0,0,0,0.62)` | 正文 |
| `--caption` | `rgba(0,0,0,0.45)` | 辅助说明 |
| `--line` | `rgba(0,0,0,0.08)` | 细线 |
| `--success` | `#02B940` | 仅确认类反馈 |

不用暗色模式。

### 4.2 字

```
-apple-system, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif
```

正文 14 / 400 / 行高 22。顶栏品牌 16 / 600。启动页标题可以大于正文，但不做 48px 展示字，也不用全大写英文。

### 4.3 形状与间距

- 主按钮、次按钮：胶囊
- 卡片圆角 12；大卡 16
- 内容区最大宽 **1120px**，水平 padding 24
- 旧物图、置办图 72；房源列表图 72 或 88

### 4.4 层级

| 层 | 表现 |
|---|---|
| 画布 | `#F5F5F5` |
| 卡片 | 白底 |
| 顶栏 | 白底，高约 56，底边细线 |
| 右侧栏 | 白底，从右侧进入，约 200ms |
| 引导 | 挖空高亮 + 说明卡，可跳过 |

## 5. 全站骨架

```
┌──────────────────────────────────────────────┐
│ 顶栏：logo +「搬伴」    产品说明 或 重置 Demo │
├──────────────────────────────────────────────┤
│                                              │
│     主内容（max 1120）                        │
│                                              │
└──────────────────────────────────────────────┘
```

- 启动页右侧按钮是「产品说明」（次按钮）。打开后右侧栏标题就是「产品说明」。
- 看板右侧按钮是「重置 Demo」（次按钮，灰底胶囊）。
- 没有页脚。模型边界写在产品说明里。

## 6. 分页面

### 6.1 启动页

垂直居中一块白卡，不是全屏大图。

- 24px 圆角方标，图为 `assets/logo.svg`
- 标题：「搬伴」
- 一句说明：「AI作伴，定制完整搬家计划」
- 输入：灰底胶囊多行框，占位「输入你的需求」，右侧麦克风
- 次按钮「Demo试运行」+ 主按钮「生成计划」
- 生成中：主按钮内「生成中」和红点，下方三行进度

不要背景视频、粒子或大红渐变。

### 6.2 看板

自上而下：

**你的要求**

- 标签「你的要求」
- 原文。日期、地点、预算、物品名等划线，红字浅红底
- 「编辑」为次按钮。编辑时出现「取消」和主按钮「保存」
- 「!」说明划线是识别出的关键信息

**双轨（宽屏并排，间距 16）**

| 左列 旧房清理 | 右列 新房安置 |
|---|---|
| 无照片：虚线空态「暂未上传照片」，次按钮「上传房屋照片」，主按钮「用示例房间」 | 未选：「暂未选择新房」，主按钮「选一套」 |
| 扫描中：房间图 + 扫描线 +「正在按这张照片认旧物」 | 选择中：一行一条房源 |
| 扫描后：房间图，其下旧物卡（72 图、名称、转卖/丢弃/带走） | 已选：封面、标题、星、月租、通勤、起租、宠物；次按钮「换一套」 |
| 转卖后出现「生成转卖帖」 | 已选且未置办：「还没置办家具。」主按钮「置办家具」 |

旧物三选一是分段文字。选中项字重加重并带红下划线，不要做成三颗大色块。

**月历**

标题「日程表」。右侧是月份和左右箭头。退租、过渡、起租、报到标在对应日期上。未选定或冲突用红字。

### 6.3 转卖帖（右侧栏）

宽约一列。预设图、标题、正文、`#标签`。主按钮「复制文案」。关闭是次按钮。

### 6.4 房源详情（右侧栏）

标题旁有「来源 小红书」。字段按列表：月租、位置、通勤、起租、宠物，下面是一句卖点和标签。主按钮「就这套」。

### 6.5 按通勤筛房（右侧栏，更宽）

30 / 45 / 60 用文字 Tab 和红下划线。列表一行一条，不是瀑布流。选中行左边框为红。空状态一行说明，建议放宽到 60 分钟。

### 6.6 产品说明（右侧栏）

分块标题：搬伴是什么、为什么要用 AI、AI 能做什么。用图标行，不用营销彩条，也不做页脚。

### 6.7 引导

半透明遮罩，目标控件挖空。说明卡有步骤序号、标题、一句正文。需要用户操作时写明要点哪一个；其余给「下一步」。非最后一步可「跳过」。

## 7. 组件

| 组件 | 做法 |
|---|---|
| 主按钮 | `#FF2E4D` 白字，胶囊 |
| 次按钮 | `--fill-2` 底，深色字，同胶囊 |
| 文字按钮 | 无底，红色 |
| 输入 | 灰底，无粗描边 |
| 划线 | 红字 + `--red-tint` |
| 旧物/置办卡 | 白，左图右文 |
| 已砍掉 | 整行变淡，Chip「已砍掉」 |
| 已降级 | 原价划线 + 现价，Chip「已降级」 |
| 右侧栏 | 从右进入，无整页厚重弹窗 |
| Toast | 底部居中，深色底白字，约 2 秒 |

启动页同时只有一颗红主按钮。看板上，当前空态的那一颗（用示例房间、选一套、置办家具）可以是红的，不和另一颗红按钮并排抢。

---

## 8. 状态

| 状态 | 视觉 |
|---|---|
| 旧房未拍照 | 虚线空态 |
| 扫描中 | 扫描线扫过房间图 |
| 旧物待处理 | 三个选项都是常规字重 |
| 已转卖 / 丢弃 / 带走 | 对应项红下划线；金额说明出现在下方 |
| 新房未选 | 虚线空态「暂未选择新房」 |
| 新房已选 | 白卡 + 星 |
| 新房被清空 | 空态红边闪一次 |
| 置办未打开 | 「还没置办家具。」 |
| 模型回退 | Toast：「这次按原句本地拆了一版」 |

---

## 9. 动效

- 侧栏 200ms ease-out
- 进入看板、旧物、房源、置办可逐条延迟出现
- 生成中红点脉冲
- 不要全屏 Lottie，不要粒子

---

## 10. 响应式

| 宽 | 布局 |
|---|---|
| ≥1080 | 双轨并排，侧栏在右侧 |
| 768–1079 | 双轨上下叠，先旧后新 |
| <768 | 顶栏和输入仍可用；侧栏改为自下而上 |

---

## 11. 反模式

- 整页大红渐变、玻璃拟态、霓虹、暗黑赛博
- 把看板做成看板列或表格
- 房源墙做成瀑布流
- 再加一套蓝或紫当作「AI 色」
- 页脚再重复一篇模型说明
- 一进来就把旧物和置办铺满，留白被吃掉

---

## 12. 验收

- [ ] 画布灰、卡片白、主按钮红，红的面积远小于白
- [ ] 顶栏是「搬伴」，启动页是「产品说明」，看板是「重置 Demo」
- [ ] 启动页是「AI作伴，定制完整搬家计划」，输入占位是「输入你的需求」
- [ ] 生成后的第一屏，旧房和新房是空态
- [ ] 筛房是列表；笔记卡只出现在转卖帖和房源详情
- [ ] 没有页脚
