# 搬伴

跨城搬家的计划看板。用一句话说清退租、报到、预算和通勤，旧房、新房和时间轴先摊开；缺的地方留白，等你补上。改一句要求，日期和花费一起重算。

线上地址：[https://halo-welt.github.io/AI-banban/](https://halo-welt.github.io/AI-banban/)。自己写一句话后点「生成计划」会调用 DeepSeek；「Demo 试运行」不调用模型。

没有登录，没有云端存档，房源和价格来自本地数据。模型负责读原句、写转卖帖和说明这次为什么变；筛房、算账、砍置办由前端规则完成。模型调不通时，会落到内置剧本，看板结构不变。

GitHub Pages 上没有 `/api/chat`。页面发现这层转发不可用时，会由浏览器直接请求 DeepSeek。Key 不进仓库，发布时从仓库 Secret `DEEPSEEK_API_KEY` 写进页面。公开站点的脚本里能看到这把 Key，请在 DeepSeek 控制台限制用量。

## 本地运行

需要 Python 3。在仓库根目录执行：

```bash
python3 server.py
```

或：

```bash
npm start
```

浏览器打开 [http://127.0.0.1:8766/](http://127.0.0.1:8766/)。

`server.py` 同时做两件事：提供静态页面，并把 `/api/chat` 转发到 DeepSeek。直接用 `python3 -m http.server` 也能打开页面，但没有这层转发时，模型请求更容易失败，界面会改用内置剧本。

## 建议走一遍

默认故事是：6 月 30 日北京退租，7 月 15 日到上海陆家嘴报到，一次性预算 8000，通勤不超过 45 分钟。

1. 启动页点「Demo 试运行」，或自己改一句话后点「生成计划」。
2. 看板上旧房、新房先是空的。给旧房拍照，认出沙发、桌椅、床垫，再选转卖、丢弃或带走。转卖会生成小红书帖，可复制，不会真发出去。
3. 点「按通勤筛房」，选一套房源写回计划。路演可先选民生路那套（通勤合格、不能养猫、6 月 15 日起租）。
4. 点「置办家具」，新家要买的东西补上。一次性花费和月租金分开算，月租不进 8000 预算。
5. 再追加一句约束，例如「必须能养猫」或把一次性预算改到 6000。日期、花费和筛房条件会一起更新，并写出这次差在哪里。
6. 看板右上角「重置 Demo」清空后回到启动页。



## 目录


| 路径             | 内容                     |
| -------------- | ---------------------- |
| `index.html`   | 入口页                    |
| `js/app.js`    | 界面与交互                  |
| `js/engine.js` | 计划、账本、砍预算、时间轴          |
| `js/ai.js`     | 模型调用与失败回退              |
| `server.py`    | 本地静态服务与 `/api/chat` 转发 |
| `data/`        | 默认计划、旧物、置办、房源、出帖兜底文案   |
| `docs/`        | 申报文案、功能设计、视觉设计、实现约定    |
